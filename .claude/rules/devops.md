## DevOps Design Patterns

- **Blue-Green Deployment** — maintain two identical environments; switch traffic on release
- **Pipeline as Code** — define CI/CD pipelines in version-controlled files
- **Infrastructure as Code (IaC)** — provision infrastructure via code, not manual steps
- **Health Checks** — expose readiness/liveness endpoints for all services
- **Log Aggregation** — centralize logs; never rely on per-instance log access
