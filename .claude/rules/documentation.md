# Documentation

## Comments
- Short comment for every function, class, etc. (maximum 3 words)
- For definig functions use this format     

"""Save a list of promises to the database.

    Args:
        promises: List of promises, each with promise, source, and date fields.
    """
- For execute code use one liner (e.g. "# This executes a scraper")
## README
- Every project must have a **README**.
- Keep the README **simple** and **up to date** with every significant change.
- Use only these sections: **Contents**, **Usage**, **Links**, **References**.

## Changelogs
- Maintain a `CHANGELOG.md` and **update it with every release**.  
- Categorize entries consistently: **Added, Changed, Deprecated, Removed, Fixed, Security**.
